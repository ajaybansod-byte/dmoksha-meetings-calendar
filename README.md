# D'Moksha Meetings Calendar

Designer meetings, field visits (installations, collections, measurements…), support-staff / factory / operations
portal, travel expenses and accounts payments for D'Moksha Homes' curtain-at-home service.

## Live links

| Who | Link | Login |
|---|---|---|
| Office (calendar, scheduling, installations, field team) | https://dmoksha-meetings-calendar.onrender.com | ERP email + password (any active user in `public.users`) |
| Accounts (field team + payments only) | same link | ERP email — users with role `accounts` get the limited view automatically |
| Support staff & designers | https://dmoksha-meetings-calendar.onrender.com/support-team | 10-digit mobile + password |
| Factory (dispatch approvals, returns, alterations) | /support-team | mobile + password (staff role `factory`) |
| Operations — Amit, Ajay (bills on behalf of staff, alteration costs) | /support-team | ERP email + password (staff role `ops`) |

`/staff` redirects to `/support-team`.

## Files

| File | What it is |
|---|---|
| `index.html` | Meetings Calendar — single-file React 18 + Tailwind + supabase-js app. Tabs: Calendar · List · Scheduling · Installations · Workload · Field team · Trash; Export; accounts view. |
| `staff.html` | Staff portal — one app, the screen depends on `staff.role`: support/designer (Meetings · Installation · Maintenance · Expenses), factory (Dispatch · Returns · Alterations), ops (Visits · Bills pending · Submitted). |
| `server.js` | Express server for Render: `/support-team` → staff.html, `/staff` → redirect, everything else → index.html. |
| `package.json`, `render.yaml` | Render Web Service config (Node, `node server.js`). |
| `DEPLOY.md` | Original first-deploy guide (June 2026). |
| `db/TABLES.md` | Every table/bucket the app uses and what it holds. |
| `db/MIGRATIONS.md` | History of schema changes made for this app (applied in Supabase). |
| `docs/` | Client ID system, ERP alteration-section prompt, staff onboarding messages. |
| `backups/` | Excel exports of the data + Client ID dry run. **Git-ignored** — contains customer data, never pushed. |

## Where the data lives

Nothing is stored on this computer except `backups/`. All data is in Supabase project **dmoksh-master-db**
(`pncdmkqhfclymmyldmas`), shared with the curtain ERP. Photos and bill screenshots are in the storage bucket `invoices`.
See `db/TABLES.md`.

## Key rules built in

- Client ID format `DC-DI-A0001` (kiosk `DC-HT-…`), generated by the database — see `docs/Client_ID_system.md`.
- Installer can't start an installation job sheet until the factory approves the dispatch (per curtain).
- Tool photos and finished-work photos are mandatory on installation job sheets; photos are compressed on the phone (≤1600 px, JPEG ~72%).
- Curtain care kit is added to the installer's tool list when the accepted estimate is ≥ ₹75,000.
- Travel bills: staff (or ops on their behalf) submit → office approves in Field team → accounts mark paid with UTR.
